Painel do cardápio

Entre com o token do GitHub que tem permissão de escrita no repositório do site.

Como criar o token?
  1. Abra github.com/settings/personal-access-tokens/new.
  2. Repository access: "Only select repositories", marque o repositório do site.
  3. Permissions → Contents: "Read and write".
  4. Gere, copie e cole aqui. Para bloquear o acesso, basta revogar o token no GitHub.
